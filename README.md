# Bombay Falooda Backend

NestJS modular-monolith backend for the Bombay Falooda restaurant management platform.

## Apps

- `api`: REST API for website, Superadmin, Franchise Owner portal and POS.
- `worker`: background jobs for notifications, backups, retries and scheduled tasks.

## First Run

```bash
npm install
npm run start:dev
```

Copy `.env.example` to `.env` before running locally.
